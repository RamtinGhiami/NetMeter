# اینترنت‌متر (NetMeter)

پایشگر مصرف اینترنت **به تفکیک دستگاه** روی ویندوز. برنامه از پنل مدیریت مودم
شمارنده‌ی ترافیک هر دستگاه را می‌خواند، آن را در یک پایگاه‌داده‌ی محلی (SQLite)
ذخیره می‌کند و یک داشبورد فارسی راست‌به‌چپ با نمودار روزانه نشان می‌دهد.

> داده‌ها فقط روی همین رایانه می‌مانند. هیچ اتصالی به اینترنت بیرونی برقرار نمی‌شود.

---

## امکانات

- مصرف **امروز / این ماه / کل** برای هر دستگاه (دانلود و آپلود جدا)
- **نام دلخواه و دسته‌بندی** برای هر دستگاه (گوشی، لپ‌تاپ، تلویزیون، کنسول و…)
- نمودار ستونی ۱۴، ۳۰ و ۹۰ روزه‌ی کل شبکه
- تاریخچه‌ی ۳۰ روزه‌ی هر دستگاه با کلیک روی سطر آن
- تشخیص خودکار دستگاه آنلاین/آفلاین و سرعت لحظه‌ای
- نام و سازنده‌ی دستگاه از روی MAC (جدول OUI داخلی)
- شروع خودکار با ویندوز (اختیاری، بدون نیاز به دسترسی ادمین)
- خروجی CSV از مصرف دستگاه‌ها و ترافیک مودم
- رمز مودم با **DPAPI ویندوز** رمزنگاری می‌شود (به حساب کاربری شما گره می‌خورد)
- رابط وب فقط روی `127.0.0.1` گوش می‌دهد (قابل تغییر)
- **سبک**: نسخه‌ی نصبی حدود ۲۴ مگابایت، حافظه‌ی مصرفی ~۴۵ مگابایت، بدون
  سرویس ویندوز و بدون نیاز به دسترسی ادمین

## شروع سریع

```powershell
cd "C:\Users\Pacific\Documents\Default Project"
pip install -r netmeter\requirements.txt
python -m netmeter
```

مرورگر خودکار روی <http://127.0.0.1:8787/> باز می‌شود. اولین بار دکمه‌ی
**راه‌اندازی** را بزنید و آدرس مودم، نام کاربری و رمز عبور پنل را وارد کنید.

بدون پنجره‌ی کنسول:

```powershell
pythonw netmeter\run.pyw        # یا دوبار کلیک روی netmeter\start.vbs
```

برای دیدن ظاهر و نمودارها بدون مودم:

```powershell
python -m netmeter --demo --port 8899
```

## نصب روی ویندوز

هر سه روش زیر بدون دسترسی ادمین کار می‌کنند و کنار هم قابل استفاده‌اند.

### ۱) نسخه‌ی نصبی (Setup.exe) — ساده‌ترین

```powershell
powershell -ExecutionPolicy Bypass -File netmeter\build.ps1
```

اگر NSIS نصب باشد، فایل `netmeter\dist\NetMeter-Setup-0.1.0.exe` هم ساخته
می‌شود (نصب NSIS: `winget install NSIS.NSIS`). بعد فقط روی همان فایل دوبار
کلیک کنید:

- نصب در `%LOCALAPPDATA%\NetMeter` (بدون پنجره‌ی UAC)
- میان‌بر روی دسکتاپ و منوی استارت
- گزینه‌ی «اجرا با ویندوز»
- حذف از **Settings → Apps** یا از منوی استارت → NetMeter → Uninstall

### ۲) نصب بدون Setup (اسکریپت)

```powershell
powershell -ExecutionPolicy Bypass -File netmeter\install.ps1
# اجرای خودکار با ویندوز و باز کردن برنامه بعد از نصب:
powershell -ExecutionPolicy Bypass -File netmeter\install.ps1 -Autostart -Start
```

اگر `netmeter\dist\NetMeter\NetMeter.exe` وجود داشته باشد همان نصب می‌شود
(بدون نیاز به پایتون). وگرنه از سورس با یک محیط مجازی خصوصی نصب می‌شود
(حدود ۱۵ مگابایت؛ پایتون ۳ باید نصب باشد).

حذف:

```powershell
powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\NetMeter\uninstall.ps1"
# پاک کردن تاریخچه‌ی مصرف هم:  -PurgeData
```

### ۳) نسخه‌ی portable

پوشه‌ی `netmeter\dist\NetMeter` را هرجا کپی کنید و `NetMeter.exe` را اجرا
کنید. داده‌ها در `data\` کنار همان فایل می‌مانند (حدود ۲۴ مگابایت).

> در نسخه‌ی نصب‌شده برنامه در `%LOCALAPPDATA%\NetMeter\app` و داده‌ها در
> `%LOCALAPPDATA%\NetMeter\data` هستند. حذف برنامه به‌طور پیش‌فرض تاریخچه را
> پاک نمی‌کند.

## نام و دسته‌بندی دستگاه‌ها

روی هر سطر در جدول «دستگاه‌ها» کلیک کنید. در کشوی بازشده:

1. **نام دلخواه** را بنویسید (مثلاً «گوشی سارا»). خالی گذاشتن = نام پیش‌فرض مودم.
2. **دسته‌بندی** را انتخاب کنید: گوشی، تبلت، لپ‌تاپ، کامپیوتر، تلویزیون،
   کنسول بازی، پرینتر، دوربین، لوازم هوشمند، شبکه، سایر.
3. **ذخیره** را بزنید.

نام و دسته با MAC دستگاه ذخیره می‌شوند، پس بعد از ری‌استارت مودم یا تغییر IP
باقی می‌مانند و در جدول دستگاه‌ها، جست‌وجو و خروجی CSV اعمال می‌شوند.

## تست اتصال بدون ذخیره‌ی رمز

اگر نمی‌خواهید رمز در حافظه بماند یا می‌خواهید ببینید مودم چه فیلدهایی
برمی‌گرداند:

```powershell
python -m netmeter.diag
```

رمز با `getpass` گرفته می‌شود (روی صفحه چاپ نمی‌شود) و فقط برای همان تست
استفاده می‌شود. در پایان می‌پرسد که تنظیمات ذخیره شود یا نه.

> ⚠️ مودم‌های Huawei بعد از چند ورود ناموفق موقتاً قفل می‌کنند
> (`remaincount` / `tobelockedtime`). اگر فقط یکی دو فرصت دارید، اول رمز را
> در خود پنل مودم امتحان کنید.

## پشتیبانی از مودم‌ها

| برند / سیستم | وضعیت | منبع آمار هر دستگاه |
|---|---|---|
| Huawei HiLink / 5G CPE (H153, H155, H165, …) | ✅ پیاده‌سازی شده | `system/HostInfo` |
| TP-Link Archer | 🔜 نقشه‌ی راه | `admin/data/network_map` یا `wlan_host_list` |
| OpenWrt / LEDE | 🔜 نقشه‌ی راه | `ubus` یا `nlbwmon` |
| AsusWRT | 🔜 نقشه‌ی راه | `appGet.cgi` |
| میکروتیک RouterOS | 🔜 نقشه‌ی راه | REST API / SNMP |
| سایر مودم‌ها | ⚠️ محدود | فقط ترافیک کل (WAN) |

مودم تست‌شده: **Huawei H155-383 (5G CPE 5)** با فرم‌ور HiLink.

معماری آداپترها طوری است که افزودن برند جدید فقط نوشتن یک کلاس در
`netmeter/routers/` است؛ بقیه‌ی برنامه تغییری لازم ندارد.

## چطور مصرف محاسبه می‌شود؟

پنل مودم برای هر دستگاه شمارنده‌ی **تجمعی** `RxKBytes` و `TxKBytes` می‌دهد.
برنامه هر چند ثانیه یک بار این دو عدد را می‌خواند و اختلاف آن با نمونه‌ی قبلی
را به مصرف روز دستگاه اضافه می‌کند:

```
delta = counter_now - counter_prev
```

- اگر شمارنده **کوچک‌تر** شود (ری‌استارت مودم یا ریست شمارنده)، فقط مقدار جدید
  ثبت می‌شود تا مصرف الکی ساخته نشود.
- دستگاهی که برای اولین بار دیده می‌شود، فقط «نقطه‌ی مبنا» ثبت می‌شود و
  ترافیک گذشته‌اش به حساب کاربر نوشته نمی‌شود.
- ترافیک کل مودم (WAN) هم به‌طور جداگانه از
  `monitoring/traffic-statistics` خوانده می‌شود تا اگر دستگاه‌ها پشت
  یک روتر دیگر باشند باز هم تصویر کلی داشته باشید.

این روش به «پایش بسته» یا SNMP روی خود ویندوز نیاز ندارد و از دید مودم
معمولی است.

## تنظیمات

فایل `%LOCALAPPDATA%\NetMeter\config.json` (یا پوشه‌ی `data/` کنار فایل اجرایی
در نسخه‌ی portable) شامل این کلیدهاست:

| کلید | توضیح |
|---|---|
| `router_url` | آدرس پنل مودم، مثلاً `https://192.168.70.1` |
| `username` | نام کاربری پنل (پیش‌فرض `admin`) |
| `password_enc` | رمز رمزنگاری‌شده با DPAPI — دستی ویرایش نکنید |
| `poll_interval` | فاصله‌ی نمونه‌برداری (۵ تا ۳۶۰۰ ثانیه) |
| `quota_gb` | سهمیه‌ی ماه برای نمایش درصد مصرف (۰ = بدون سهمیه) |
| `reset_day` | روز شروع دوره‌ی مصرف: `0` = ابتدای ماه شمسی، `1..31` = آن روز از ماه میلادی |
| `offline_after_min` | بعد از چند دقیقه بی‌خبری دستگاه آفلاین حساب شود |
| `bind_host` / `port` | آدرس و پورت داشبورد |
| `start_with_windows` | اجرا با ورود به ویندوز |

## عیب‌یابی

**«اتصال به مودم ممکن نشد»**
- آدرس را با `https://` بزنید؛ بعضی مودم‌ها روی HTTP ریدایرکت می‌کنند.
- اگر VPN یا پروکسی سیستم (مثل Clash) روشن است، ترافیک شبکه‌ی محلی را
  دور بزنید؛ برنامه خودش `trust_env=False` دارد ولی TUN/VPN می‌تواند
  مسیر `192.168.x.x` را بدزدد.
- گواهی مودم self-signed است؛ برنامه فقط برای همان آدرس آن را نادیده می‌گیرد.

**کد `108006` یا «نام کاربری یا رمز اشتباه»**
- نام کاربری پیش‌فرض `admin` است، اما برخی اپراتورها حساب دومی با نام دیگر
  می‌سازند. همان نامی را وارد کنید که در صفحه‌ی ورود مودم نوشته شده.
- بعد از چند تلاش، مودم ۱ تا ۵ دقیقه قفل می‌کند (`108007`). صبر کنید و
  دوباره تلاش کنید.
- اگر پنل مودم باز است، یک نشست دیگر می‌تواند مانع ورود شود (`108003`/`108005`);
  از پنل خارج شوید.

**دستگاه‌ها نمایش داده نمی‌شوند**
- بعضی حساب‌های «کاربر مهمان» اجازه‌ی خواندن `system/HostInfo` ندارند
  (خطای `100003`). با حساب مدیر وارد شوید.
- اگر مودم شما پشت روتر دیگری است، آمار هر دستگاه مربوط به همان مودم است.

**برنامه بالا نمی‌آید**
- پورت ۸۷۸۷ اشغال است؛ از تنظیمات پورت دیگری بگذارید یا
  `python -m netmeter --port 8899` اجرا کنید.
- فایل لاگ: `%LOCALAPPDATA%\NetMeter\netmeter.log`

## ساخت نسخه‌ی اجرایی و نصبی

```powershell
powershell -ExecutionPolicy Bypass -File netmeter\build.ps1
```

خروجی‌ها:

| فایل | توضیح |
|---|---|
| `netmeter\dist\NetMeter\NetMeter.exe` | نسخه‌ی portable (~۲۴ مگابایت) |
| `netmeter\dist\NetMeter-Setup-0.1.0.exe` | نسخه‌ی نصبی (اگر NSIS نصب باشد) |

برای ساخت Setup، NSIS 3 را نصب کنید (`winget install NSIS.NSIS`) یا فقط با
`install.ps1` نصب کنید. برای ساخت فقط EXE: `-NoInstaller`.

## ساختار پروژه

```
netmeter/
  __main__.py      نقطه‌ی ورود و CLI
  config.py        تنظیمات و تشخیص درگاه شبکه
  dpapi.py         رمزنگاری رمز با DPAPI ویندوز
  db.py            SQLite + تجمیع روزانه + نام/دسته‌ی دستگاه + CSV
  collector.py     حلقه‌ی نمونه‌برداری و محاسبه‌ی delta
  server.py        HTTP محلی + JSON API + فایل‌های وب
  diag.py          ابزار تست اتصال
  autostart.py     اجرای خودکار با ویندوز
  util.py          تبدیل واحد، OUI، تاریخ جلالی
  routers/
    base.py        قرارداد آداپتر و مدل‌های داده
    huawei.py      ورود SCRAM و خواندن HostInfo/WAN
  web/             داشبورد فارسی (HTML/CSS/JS بدون build)
  run.pyw          اجرای بدون کنسول
  run.bat          اجرای ساده
  start.vbs        میان‌بر مخفی برای ویندوز
  install.ps1      نصب در پوشه‌ی کاربر + میان‌بر + ثبت در Apps
  uninstall.ps1    حذف کامل (با گزینه‌ی -PurgeData برای تاریخچه)
  installer.nsi    اسکریپت Setup.exe با NSIS
  build.ps1        ساخت EXE و Setup
  requirements.txt وابستگی‌ها
  README.md / NOTICE / LICENSE
```

## حریم خصوصی و امنیت

- داشبورد پیش‌فرض فقط از `127.0.0.1` در دسترس است. اگر `bind_host` را
  `0.0.0.0` بگذارید، هر کسی در شبکه‌ی محلی می‌تواند آمار را ببیند (فقط خواندنی).
- رمز مودم با DPAPI رمزنگاری می‌شود و فقط با همان حساب ویندوز قابل بازگشایی است.
- برنامه هیچ داده‌ای به بیرون نمی‌فرستد؛ فقط با آدرس مودم ارتباط دارد.
- برای امنیت بیشتر، حساب کاربری جداگانه‌ای در مودم بسازید که فقط اجازه‌ی
  مشاهده داشته باشد.
